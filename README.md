## 使用规则

- PS Codex 和 PL Codex 都可以查看整个仓库；
- PS Codex 修改 ps/；
- PL Codex 修改 pl/；
- 双方共同使用共享/协议/；
- 正式协议变更必须经过 PS/PL 工程师确认；
- 两台电脑分别克隆仓库，不共用一个本地目录；
- 双方直接在 main 上协作，不使用 Pull Request；
- 开始工作前拉取，完成工作后提交并推送。

详细规则见 COLLABORATION.md。
