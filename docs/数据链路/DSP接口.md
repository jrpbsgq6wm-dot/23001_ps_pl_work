# DSP 接口

状态：待 PS/PL 工程师共同确认

需要明确：

- DSP 输入数据来源；
- DSP 输入启动条件；
- DSP 输入数据长度；
- DSP 输入数据格式；
- DSP 忙/空闲状态；
- DSP 处理完成标志；
- DSP 输出数据格式；
- DSP 输出有效长度；
- DSP 超时；
- DSP 错误码；
- PL 到 DSP、DSP 到 PL 的寄存器和内存关系；
- BUILD_ID 和协议版本兼容方式。

## 交互步骤

~~~text
1. PS/PL 完成配置
2. PL 准备 IQ 数据
3. PL 启动 DSP 输入
4. DSP 接收并处理
5. DSP 返回结果
6. PL 标记结果有效
7. PS 收到事件并读取
8. PS 校验并发送显控
~~~

每一步都必须有对应的状态、寄存器或数据证据。
