# 协作记录

本目录用于记录 PS Codex 和 PL Codex 之间的交接，不依赖聊天窗口保存上下文。

每次有明确问题或接口交接，建立一个新文件，例如：

~~~text
001-PL-寄存器设计.md
002-PS-寄存器映射反馈.md
003-PL-DSP接口回复.md
~~~

## 记录格式

~~~text
编号：
来源：PS Codex / PL Codex
目标：PS Codex / PL Codex
当前分支：
当前提交：
相关文件：
问题或变更：
证据：
需要对方完成的动作：
状态：待回复 / 已回复 / 待工程师裁定 / 已确认 / 已实现 / 已验证
~~~

PL 的寄存器定义先提交，PS 拉取后评审和反馈。PS 不理解的字段必须记录并询问，不允许自行猜测。
