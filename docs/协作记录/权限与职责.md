# 权限与职责

## 查看权限

PS Codex 和 PL Codex 都可以查看整个仓库：

- PS Codex 可以查看 pl/ 下的 PL 配置、寄存器导出、DMA、中断和 DSP 接口；
- PL Codex 可以查看 ps/20260916/ 下的 PS 源码和 ps/device-tree/ 下的设备树；
- 双方都可以查看共享/ 下的正式协议、版本、测试资料，以及 docs/ 下的协作记录和沟通记录。

## 修改职责

| 目录 | PS Codex | PL Codex |
|---|---|---|
| ps/20260916/ | 可修改 | 只读查看 |
| ps/device-tree/ | 可修改 | 只读查看 |
| pl/ | 只读查看 | 可修改 |
| 共享/协议/ | 提供 PS 侧使用和验证内容 | 提供 PL 侧接口内容 |
| 共享/版本/ | 提供 PS 适配版本 | 提供 PL build ID 和协议版本 |
| 共享/测试/ | 提供 PS 验证结果 | 提供 PL 测试数据和依据 |
| docs/协作记录/ | 可新增 PS 消息 | 可新增 PL 消息 |

## 发现对方问题时

PL Codex 发现 PS 代码或设备树问题时，只在协作记录中说明问题、证据和建议，不直接修改 ps/。

PS Codex 发现 PL 配置或寄存器问题时，只在协作记录中说明问题、证据和建议，不直接修改 pl/。

修改由目录所属 Codex 完成。双方都可以读取修改后的结果并继续联调。

## Git 约束

双方使用同一个 main 分支协作，但每次提交前必须先拉取最新代码。一次提交只修改自己负责的目录和对应的协作记录。
