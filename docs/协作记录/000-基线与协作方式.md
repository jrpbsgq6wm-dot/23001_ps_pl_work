协作范围：

~~~text
湿端 IQ → PL → DSP → PL → PS → 显控
~~~

PS Codex 负责 PS 源码、设备树、UIO 映射、数据接收解析和显控上传。

PL Codex 负责 PL 配置、寄存器、DMA、FIFO、中断、DSP 输入输出和 build ID。

双方使用同一个 GitHub 仓库和同一个 rewrite/data-path 分支。两边都可以查看整个仓库，包括对方的源码和配置。每次工作前先 pull，每次工作后提交并 push。PS Codex 只修改 ps/，PL Codex 只修改 pl/；发现对方目录的问题时，通过协作记录通知目录所属 Codex。

工程师只裁定硬件行为、协议、寄存器、时序、错误恢复和最终验收；普通实现、代码整理、测试脚本和文档由两个 Codex 自主完成。
