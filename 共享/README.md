# 共享资料

本目录保存 PS Codex 和 PL Codex 共同使用的资料。共享资料只有一份正式版本，双方都从这里读取，不在 ps/、pl/ 或其他目录复制同一份协议。

## 目录

~~~text
共享/
├── 协议/       正式的寄存器、数据帧、DMA、IRQ、DSP和端到端流程
├── 版本/       接口版本、PL build ID和兼容关系
└── 测试/       共享测试数据、期望结果和验证说明
~~~

当前协议文件在共享/协议/：

- 端到端数据流程.md
- 寄存器协议.md
- 数据帧格式.md
- DMA与中断.md
- DSP接口.md

## 修改规则

双方 Codex 都可以查看共享目录。共享/协议/中的内容如果会改变 PS 可见接口，必须先在 docs/协作记录/请求/建立请求，由 PS/PL 工程师确认后再修改。

PL Codex 可以起草 PL 接口内容，PS Codex 可以补充 PS 使用和验证内容。最终地址、位定义、数据长度、时序、错误行为和版本由工程师裁定。

共享/版本/和共享/测试/由双方按请求记录协作维护。不要直接覆盖对方尚未提交的修改，也不要在其他目录建立同名协议副本。
